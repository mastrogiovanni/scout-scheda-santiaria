# Simbolo Scout d’Europa

`fse-emblem.png` riprende la croce rossa con il giglio giallo dal logo pubblicato sul sito ufficiale degli Scout d’Europa FSE: https://media.fse.it/fsescout/uploads/2023/11/logo-fse-1024x296.png (https://fse.it/, consultato il 18 ottobre 2026).

È stato isolato il solo emblema, conservandone proporzioni e colori. Le icone dell’app del campo usano lo stesso emblema su fondo blu. Il simbolo resta di pertinenza dell’associazione.
